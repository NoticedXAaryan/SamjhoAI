# Architecture decision records

ADRs record decisions that are expensive to reverse or whose original context is easy to lose.

Statuses:

- `proposed`: recommendation awaiting explicit adoption or implementation proof.
- `accepted`: current governing decision.
- `superseded`: retained for history and linked to its replacement.
- `rejected`: evaluated but not chosen.
